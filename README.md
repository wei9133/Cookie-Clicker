🛑 常見問題 (FAQ)

Q: 新版的「矩陣狙擊手 (Sniper)」要怎麼設定？
A: 打開「顯示記憶 (花園網格)」，點擊 「🎯 編輯監控區」。此時面板會切換為紫色標題。點擊網格內的空格：

    輸入 *：代表只要這格長出任何未解鎖的植物 (紫框)，就發發出警報。

    輸入 ID (例如 21)：代表這格只要長出 JQB，就發出金色警報。
    設定完後，點擊下方的「儲存」即可寫入 Slot。

Q: 狙擊手觸發警報後會發生什麼事？
A: 網頁上方的分頁圖示 (Favicon) 會動態被繪製成金色方塊或紫色方塊，並顯示座標 (例如 [🎯A1])。同時系統會啟動「憲法級阻斷」，絕對禁止網頁自動重啟，直到您親自去花園處理該植物。

Q: 為什麼我的銀行貸款 (Loan 2) 沒有自動購買？
A: 請檢查：1. 倍率是否達到門檻 (預設 300k)。2. 是否處於冷卻中（日誌顯示「休眠」）。3. 是否重新整理過網頁？(v9.1.10 起支援持久化冷卻，F5 後冷卻依然有效)。

Q: 為什麼按了 F4 (強制突變) 之後，泥土沒有變化？
A: 這是 v9.1.10 加入的 DOM 優化。如果當前泥土已經是您設定的目標（例如已經是肥料），系統就不會再多發送一次點擊指令。

Q: Godzamok 連擊結束後，為什麼我的資金鎖定沒有解開？
A: 這是 智慧快照 (Immutable Snapshot) 功能。如果您在觸發核彈前 已經 手動鎖定了資金，腳本會在連擊結束後 恢復為鎖定狀態。只有在觸發前是「未鎖定」的狀態，結束後才會自動幫您解鎖。

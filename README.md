## 🚀 v9.1.10 新版亮點 (What's New)

### 🏦 銀行貸款：智慧休眠 (Loan Ranger: Smart Sleep)
*   **持久化冷卻 (Persistence):** 當自動購買「貸款 2 (Loan 2)」成功後，系統會強制進入 **40 分鐘** 的長冷卻期。此狀態會寫入存檔，即使**刷新網頁 (F5)**，冷卻時間也不會重置，徹底防止因重啟導致的重複購買虧損。
*   **盲打策略 (Blind Fire):** 當 CpS 倍率超過門檻（預設 300,000x）時自動觸發。若條件不符或購買失敗，則進入 20 秒短休眠，大幅降低 API 負載。
*   **防誤觸機制:** 在控制面板重置冷卻時間時，現在會彈出 **二次確認視窗**，防止誤觸導致保護失效。

### 🌿 泥土聯動優化 (Smart Soil Sync)
*   **智慧切換:** 使用熱鍵 **F4** 強制開啟變異時，系統現在會先檢查當前泥土狀態。若已經是目標泥土（如肥料），將不再發送多餘的點擊指令，減少無效的 DOM 操作。

### 🛡️ 安全性與容錯 (Security & Resilience)
*   **季節購買加固:** 調整了購買過濾器的順序，將「非切換器 (Non-toggle)」檢查移至最優先順位，防止因遊戲 API 變動導致誤買季節開關而卡死。
*   **Unjamming Protocol:** 解除 F9 (戰術核彈) 的鎖定限制。現在 F9 擁有最高中斷權，即使在異常狀態下也可強制重置並執行戰術。
*   **HUD 容錯:** 修復了遊戲剛載入時，花園資訊面板可能導致報錯的問題。

### 📊 花園 HUD 視覺增強
*   **陣型名稱顯示:** 花園右側的嵌入式控制台 (Embedded Sidebar) 現在會即時顯示當前載入的「陣型名稱」(例如 "Layout 1" 或您的自訂名稱)，狀態一目瞭然。

## 🛑 常見問題 (FAQ)

**Q: 為什麼我的銀行貸款 (Loan 2) 沒有自動購買？**
A: 請檢查：1. 倍率是否達到門檻 (預設 300k)。2. 是否處於冷卻中（日誌顯示「休眠」）。3. 是否重新整理過網頁？(v9.1.10 支援持久化冷卻，F5 後冷卻依然有效)。

**Q: 我按了「重置冷卻」為什麼彈出一個視窗？**
A: 這是 v9.1.10 新增的安全機制。手動重置冷卻非常危險，可能導致在無 Buff 狀態下重複購買貸款造成巨額虧損，因此需要您二次確認。

**Q: 為什麼按了 F4 之後泥土沒有變化？**
A: v9.1.10 優化了邏輯。如果當前泥土已經是您設定的目標（例如已經是肥料），系統就不會再多此一舉去點擊它，這是正常的效能優化。

**Q: Godzamok 連擊後，為什麼我的資金鎖定沒有解開？**
A: 這是 **智慧鎖定** 功能。如果您在觸發連擊 **之前** 就已經手動鎖定了資金，腳本會在連擊結束後 **恢復** 為鎖定狀態。只有在觸發前是「未鎖定」狀態，結束後才會自動解鎖。

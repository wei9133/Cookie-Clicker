1. 🤖 基礎自動化 (Core Automation)

    自動點擊與黃金餅乾： 自動點擊大餅乾、黃金餅乾、馴鹿與幸運跑馬燈，絕不漏接任何資源。

2. 🌻 終極花園管理 (Ultimate Garden)

花園是遊戲中最複雜的系統，交給腳本就對了：

    記憶陣型與自動播種： 排好你想要的種子陣型，點擊「💾 記憶陣型」。腳本會在土地空下來時，自動幫你種回去。

    聰明補種 (Net-CpS)： 系統會精準計算你現在身上的 Buff。如果你正處於「爆發期 (高 CpS)」，系統會暫停種田 (因為種子太貴)；如果處於「低產期」或吃了貸款副作用，系統會趁便宜時瘋狂補種！

3. 🎯 矩陣狙擊手系統 (Matrix Sniper System)

🎮 如何開始使用？ (Getting Started)

    安裝腳本： 確保你已安裝 Tampermonkey 擴充功能，並安裝本腳本。

    打開面板： 進入遊戲後，尋找畫面上可拖曳的 「🍪 漸層色餅乾按鈕」，點擊即可開啟/關閉控制面板。

    全局總開關 (F8)： 在面板最上方有「🟢 系統運行中」的狀態列。如果遇到緊急情況，隨時按下 鍵盤 F8，所有自動操作會瞬間凍結。

    設定保護： 在【資金】分頁中，你可以勾選「立即停止所有支出 (🔒)」，這會鎖住你的餅乾，通常用於你需要手動操作或等待 Combo 時。

    UI 自訂： 覺得介面太亂？你可以在【設定】分頁中關閉不必要的懸浮窗，甚至自訂所有側邊欄按鈕的顏色 (支援 HEX 色碼)！

🛑 常見問題 (FAQ)

Q: 為什麼腳本一直不幫我買東西？
A: 請檢查是否觸發了以下保護機制：

    你開啟了「💰 存錢模式」或「🔒 資金鎖定」。

    遊戲正在「打寶模式」(例如正在收集節日餅乾，腳本會鎖定資金直到買完所有節日掉落物)。

    你正在吃 Buff，系統為了保留花園「聰明補種」的種子錢，暫時不買建築。

Q: 新版的「防呆恢復 (Pre-Restart Recovery)」有什麼用？
A: 如果你設定了腳本每 1 小時自動重啟網頁防卡頓。你肯定希望在重啟前，把快滿的魔力用掉、把花園變異打開碰運氣吧？只要設定「防呆恢復: 5分鐘」，系統就會在重啟前 5 分鐘自動幫你解鎖魔法與變異，將掛機效益最大化！

Q: 怎麼備份我的設定？
A: 點擊控制面板的【設定】分頁，找到「📄 儲存至文件(.txt)」。這會下載一個文字檔，裡面包含你所有的開關、花園陣型、狙擊手設定。到新電腦只要點擊「📂 從文件讀取(.txt)」選取該檔案，系統就會為你完美還原！

Q: Godzamok 連擊結束後，為什麼我的資金還是被鎖定 (無法購買)？
A: 這是強大的 智慧快照 (Immutable Snapshot) 功能。如果你在觸發連擊「之前」就已經手動鎖定了資金，腳本會在連擊結束後「還原」為鎖定狀態；只有在觸發前是「未鎖定」的狀態，結束後才會自動幫你解鎖。

Q: 我的畫面左上角多了一個圓形的光球，那是什麼？
A: 那是 v9.5.0 的「糖塊雷達 (Lump Radar)」！紅色代表還很久，黃色代表快熟了，藍色代表進入倒數，綠色代表可以安全收割。你可以把滑鼠游標移上去看詳細時間，甚至可以在設定裡改變燈號的顏色。
